# PokeBank-CFW

Native Nintendo 3DS local Pokemon storage project targeting Generations 1-7.

This repository starts with a hardware/storage smoke test. It does **not** access Pokemon saves yet.

## v0.1 goals

- Native 3DS launch
- Top and bottom screen output
- Button input
- SD directory creation
- SD write/read verification
- GitHub Actions cloud build
- Ready-to-test .3dsx and .cia artifacts

The first on-console milestone is intentionally read/write testing only. Save access comes after the storage layer has passed on real hardware.
